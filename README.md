# ai-skills
Collection of AI skills required for lazy vibe coding

## Skills
- `aggressive-dry-kiss-documentation` - DRY/KISS documentation
- `az-pr-review` - code review an Azure DevOps PR
- `az-pr-create` - raise an Azure DevOps PR
- `dev-estimate` - MVP vs production hour estimate from BRD/feature CSV

Install: copy a skill folder into `~/.claude/skills/`.
